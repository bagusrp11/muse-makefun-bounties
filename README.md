# muse-makefun-bounties

Workspace Make.fun untuk akun @bagus-utami. Satu folder per bounty di `bounties/<competition-id>/`:
- `src/` — source code entry
- `docs/` — requirements, strategi, catatan juri
- `tests/` — pengujian lokal
- `submission/` — catatan submission (ID, status, hasil)

Aturan: tidak ada API key/token/private key di repo ini. File rahasia hidup di luar repo.
